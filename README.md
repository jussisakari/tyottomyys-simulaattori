# Työttömyys-simulaattori

A cartoon black comedy that runs in the browser. You are Keijo, 45, unemployed, a bit fat
and not very clean, in a 24 m² studio flat. You have one day and 4,37 € on the bank account.
Send four job applications before midnight, or Kela stops your money. Or just snooze.

**Play online:** https://jussisakari.github.io/tyottomyys-simulaattori/

**To play locally,** open `index.html` in a browser. Nothing needs to be installed, and it also
works straight from the file system. Click things in the game. `M` turns the sounds on and off.
